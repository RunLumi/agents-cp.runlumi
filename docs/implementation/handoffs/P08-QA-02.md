## Known limitations / do not assume
The test-owned host adapter maps HTTP DTOs to the real P08 client port. It is not
a shipped desktop adapter. Enrollment is a real HTTP fixture, not a client UI
flow. No Electron rendering, client SQLite migration, full desktop packaging,
production/provider proof or older-release compatibility is claimed. The port's
local_data_modified wrapper is not accepted as local-file evidence. No phase
status changes; P08-INT-02..06 remain separate work.
