## Outcome
Expose the migration and adoption contract over HTTP, without duplicating a single API P03–P07 already provides and without adding a route that can accept local content.

## In scope
- `GET /api/v1/compatibility`, unauthenticated, disclosing only platform constants and the caller's own fingerprint.
- The eight `/orgs/{org_id}/adoption/**` routes: summary, bindings, adopt, advance, rollback, remediations, resolve, telemetry, and the automation-import preview.
- `repositories/migration.rs`: SQL, row mapping, the compare-and-set guard, and the read-only P06 projection the import preview needs.
- `adoption.read` / `adoption.manage` in the central authorization module.
- Route registration in `app.rs`, with a comment saying why the compatibility route is outside the org tree.

## Explicitly out of scope
- Any route that accepts a local API key, prompt, file, or automation body. There is none, and the absence is the point.
- Creating an automation from a local one. P06 owns that, and the client does it after the user confirms the preview.
- Replacing P03's device enrollment, policy sync, or `workspace_bindings`.
- A device-authenticated migration route: a client that cannot be evaluated holds no device token, and a client that has not enrolled has no token to present.

## Acceptance criteria
- `GET /api/v1/compatibility` answers without a session, an organization, or a device.
- Every other route re-authorizes the tenant on each call and requires CSRF plus an `Idempotency-Key` on mutation.
- Every mutation leads its D1 batch with a version guard, so a stale writer loses.
- `POST .../bindings` accepts only stage 0 and is idempotent on the client's external reference.
- The rollback response carries `local_data_modified: false`.
- The import preview creates nothing and never drops a candidate.
- A telemetry report with an unknown field is refused with `telemetry_field_unknown`.
- `cargo clippy --workspace --all-targets -- -D warnings` and `cargo check --workspace --target wasm32-unknown-unknown` are clean.
- All sixteen migrations apply to a fresh local D1, and `p08:invariants` passes 17/17.
