## Acceptance criteria
- `/org/{slug}/adoption` resolves from a deep link and round-trips through `pathForSection`.
- The section is lazy and its chunk is under the 80 KiB gzip budget; the initial chunk is unchanged.
- Loading, empty, permission, error, and stale states are distinct and announced.
- The reason code and request id are shown on failure; the server's prose is never rendered.
- A workspace that adopted nothing is never described as having a problem.
- An unrecognized code renders as "unrecognized" with its raw value.
- Every interactive element is keyboard reachable and has a visible focus state.
- `prefers-reduced-motion` is respected by the only animated element.
- The stage ladder is a list with `aria-current="step"` on the current rung.
