# P05 Change Request — P05-CR-003

- Status: accepted for DE2E-INT-04; merge follows the authorized PR gate.
- Date: 2026-10-07.
- Base contract: P05-CG v1 and P05-CR-002.
- Write surface: tool decision response serializer and client private broker.

The actual desktop broker needs an authoritative argument binding. Add
`arguments_hash` to every tool-decision response, computed server-side as SHA-256
of the same canonical redacted `arguments_summary` persisted/evaluated by P05.
No raw argument field, client decision or new authority is introduced. Existing
clients can ignore the additive response field; the new managed client refuses
an allow with a missing or mismatched binding.

Approval issuance/resolution/atomic consumption retain their existing semantics.
Do not release an approval-based allow to a tool handler before grant consumption.
Prove exact response binding, mismatch refusal before effects, device-only auth
and a runtime Worker positive control before claiming full tool E2E completion.
