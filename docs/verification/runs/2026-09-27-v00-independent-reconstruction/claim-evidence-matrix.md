### Acceptance criteria with no claim

| Criterion | Why |
|---|---|
| F01 "A client cannot authenticate as another user by supplying a different `user_id`" | no verifier sends a foreign `user_id` at HTTP level; only a unit test on `user_handle_matches` |

| F24 "Feature rollback can target one org/provider before global disable" | storage-level only |

### Claims with only V0/V1 evidence but requiring V3/V4

- **VI-DATA-001** — 57 domain tests + 125 storage invariants, but no HTTP→R2 export/deletion slice.
- **VI-BUD-002** — no concurrent reservation race against real D1.
- **VI-INF-002** — no publish→rollback→inference-on-prior-version runtime slice.
- **VI-MIG-001** — no upgrade from a genuine previous schema snapshot.
- **VI-REL-001** — no live provider fault injection (429/5xx/timeout/connect failure).
- **VI-UX-002** — no accessibility scanner, no screen-reader pass, no destructive-confirmation
  interaction (the only destructive action reachable is org create, which is not destructive).

### Claims with no verifier at all

- Live AI-provider dispatch end-to-end. `LUMI_PROVIDER_ALLOWLIST` is empty by default, so
  `POST /api/v1/inference/responses` cannot dispatch in any configuration this campaign can
  set up. p04-smoke proves request/usage accounting, not a real upstream call.
- Email delivery. `send_email` is configured but no mailbox was inspected.
- Billing/payment provider. `adapters/billing/provider.rs` is tested against stubs only.

### External claims

- `VI-MIG-002` (local-only survives without control-plane sign-in; adoption/unbind does not
  upload or destroy local data) — **UNPROVEN**. Requires the Lumi Agents desktop repository.
- `VI-CON-002` (released desktop client protocol compatibility) — **UNPROVEN**. Requires a
  released client and a versioned compatibility matrix.
- `VI-OBS-001` V5 half (production request correlation, dashboards, alert routing) —
  **UNPROVEN**. No staging environment.
- Backup/restore at production scale — UNPROVEN at production volume; the rehearsal measured
  195 KiB and reported an RTO of 3.7 s in this campaign (STATUS records 2.4–2.6 s), which the
  repository itself already flags as a non-production measurement.
